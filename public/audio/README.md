# Timelapse share music

**`timelapse-share.mp3`** — cinematic loop for the public share viewer at `/share?t=…`.

| | |
|---|---|
| **Track** | [A Legend Will Rise (Orchestral)](https://opengameart.org/content/a-legend-will-rise-orchestral) |
| **License** | CC0 (public domain) — no attribution required |
| **Why this track** | Upbeat build, orchestral grit (strings/brass/drums), emotional “transformation” arc — fits progress timelapse marketing better than generic stock pop. |
| **App path** | `/audio/timelapse-share.mp3` (`TIMELAPSE_SHARE_AUDIO_SRC` in `lib/share/timelapseShare.ts`) |

If the file is missing or autoplay is blocked, the timelapse still plays; the UI shows **Tap to enable music**.
