# P1.4.0 — ShareLinks table (timelapse public share)

Additive DynamoDB table for marketing timelapse share links.

## Table: `ShareLinks`

| Attribute | Type | Key |
|-----------|------|-----|
| `shareId` | String | PK |
| `userId` | String | |
| `createdAt` | String (ISO) | |
| `expiresAt` | String (ISO) | |
| `revokedAt` | String (ISO), optional | |
| `includeWeight` | Boolean | |
| `unit` | String (`kg` \| `lbs`) | |
| `photosJson` | String (JSON snapshot) | |

Deployed via CDK `ShareLinksTable` in `infra/cdk/lib/backend-foundation-stack.ts`.

## API

- `POST /v2/share/timelapse` (JWT) — create link; requires `FF_PROGRESS_TIMELAPSE_SHARE=true` on Lambda
- `GET /v2/public/share/timelapse/{token}` (no JWT) — presigned photo URLs for viewers
- `DELETE /v2/share/timelapse/{shareId}` (JWT) — revoke

**Do not run manually** unless applying outside CDK; confirm with owner before `cdk deploy`.
