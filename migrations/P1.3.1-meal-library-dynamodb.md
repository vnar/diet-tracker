# P1.3.1 — Meal library + daily meal log (DynamoDB)

## Tables (CDK: `BackendFoundationStack`)

### `Meals`

- **PK:** `userId` (string)
- **SK:** `mealId` (string, format `MEAL#<uuid>`)
- **Attributes:** `nameLookupKey` (`${userId}#${normalizedName}`), `name`, `mealType`, optional `photoKey`, `estKcal`, `estProteinG`, optional `estCarbsG` / `estFatG`, `source` (`photo` | `manual` | `imported`), `timesLogged`, `lastLoggedAt`, `createdAt`, `updatedAt`, optional `deletedAt` (soft delete)
- **GSI `NameLookupKeyIndex`:** PK `nameLookupKey`, SK `mealId` — idempotent create by normalized dish name per user

### `DayMealEntries`

- **PK:** `dayKey` (`${userId}#YYYY-MM-DD`)
- **SK:** `entryId` (string, format `ENTRY#<uuid>`)
- **Attributes:** `userId`, `day`, `nameSnapshot`, `mealType`, optional `photoKey`, `kcal`, `proteinG`, optional `carbsG` / `fatG`, `loggedAt`, optional `notes`, optional `libraryMealId` (`MEAL#...`), optional `mealHistorySk` (for GSI sort), optional `deletedAt`
- **GSI `MealHistoryIndex`:** PK `libraryMealId`, SK `mealHistorySk` — sparse (only entries linked to a library meal)

## HTTP API routes (JWT)

- `POST /v2/food/meal-complete` — confirm food log + optional library row + day entry (requires `FF_MEAL_LIBRARY` + `FF_PHOTO_FOOD_LOG`)
- `GET|POST /v2/meals`, `GET /v2/meals/suggest-match`, `GET /v2/meals/{mealId}/history`, `PATCH|DELETE /v2/meals/{mealId}`
- `GET|POST /v2/days/{day}/meal-entries`, `DELETE /v2/days/{day}/meal-entries/{entryId}`

## Fuzzy match

- Postgres `pg_trgm` is **not** used (data store is DynamoDB). Client and Lambda use **Dice coefficient on character trigrams** (`lib/meals/fuzzyMatch.ts`), threshold **0.6**, aligned with the product spec.

## Rollback

- Set `FF_MEAL_LIBRARY=false` on the API Lambda and redeploy; UI hides library surfaces. Existing table data remains for a later re-enable.

## Reference SQL (Postgres only — not deployed here)

If the product moves to RDS, the schema from the P1.3.1 playbook can be applied as additive SQL migrations; enable `CREATE EXTENSION IF NOT EXISTS pg_trgm` only in that environment.
